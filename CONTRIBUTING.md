# Contributing

Thanks for helping grow this list! A few rules to keep quality high:

1. **It must be about AI + Laravel.** SDKs, agent frameworks, RAG, evals, skills, MCP servers, tutorials and real-world examples. General Laravel packages belong on awesome-laravel lists instead.
2. **One line, neutral tone.** Format: `* [name](link) - What it does, plainly stated.` No marketing adjectives, no emojis.
3. **Working links only.** Check that the link loads before opening a PR.
4. **No duplicates.** Search the list first.
5. **Put it in the right section**, keeping rough alphabetical order by name within each section.

Open a PR with your addition — small, focused PRs get merged fastest.
